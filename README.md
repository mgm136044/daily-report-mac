# DailyReport for macOS

하루 동안의 코딩 작업을 **자동으로 모아 요약해서 Notion에 날짜별로 정리**해 주는 macOS 메뉴바 앱.
매일 정해진 시각에 알아서 돌기 때문에, 그날 무엇을 했는지 따로 적지 않아도 기록이 쌓입니다.

메뉴바에서 확인할 수 있는 앱이고, 모든 처리는 **로컬에서** 이뤄집니다. Notion 토큰은 macOS **Keychain**에
저장되어 디스크에 평문으로 남지 않습니다.

---

## 무엇을 하나

매일 정해진 시각(기본 새벽 4시 5분, 하루 경계 04:00)에 지난 하루를 정리합니다:

1. **수집** — Claude Code 세션 · Codex 세션 · git 커밋 · 파일 변경을 프로젝트별로 모읍니다.
2. **정제** — 작업 폴더를 프로젝트 단위로 접고, 네 소스를 한 흐름으로 합치고, 잡음 명령을 걸러냅니다.
3. **요약** — Claude(또는 Codex)로 사람이 읽는 마크다운 하루 보고서를 만듭니다.
4. **적재** — Notion 데이터베이스에 날짜별로 올립니다(같은 날짜는 덮어쓰기 — 중복 없음).

Mac이 며칠 꺼져 있었어도 켜지면 밀린 날짜를 자동으로 채웁니다(최대 14일).

---

## 다운로드 & 설치

1. [Releases](https://github.com/mgm136044/daily-report-mac/releases/latest)에서 최신 `DailyReport-x.y.z.dmg`를 받습니다.
2. dmg를 열고 `DailyReport.app`을 **응용 프로그램**으로 드래그합니다.
3. 앱을 실행합니다. Developer ID로 **서명·공증**되어 있어 바로 열립니다.
   앱은 메뉴바 오른쪽 위에 **달력 아이콘**으로 나타납니다.

> 앱 안에서 **업데이트 확인** 버튼으로 새 버전을 직접 확인하고 내려받을 수 있습니다.

---

## 첫 설정

처음 실행하면 안내 창이 떠서 Notion 연결을 5단계로 도와줍니다:

1. **노션 통합 만들기** — 버튼으로 통합 페이지를 열고 새 통합을 생성해 토큰(`ntn_…`)을 복사합니다.
2. **토큰 붙여넣기**
3. **부모 페이지 링크** — 보고서가 쌓일 노션 페이지를 하나 골라 주소를 붙여넣습니다.
4. **페이지를 통합과 연결** — 그 페이지 우측 상단 `•••` → 연결 → 방금 만든 통합 추가 *(가장 자주 빠뜨리는 단계)*.
5. **연결 확인** — 앱이 그 페이지 아래에 데이터베이스를 자동으로 만듭니다.

연결한 뒤 설정에서 **매일 자동 실행**을 켜고 원하는 시각을 정하면 끝입니다.

---

## 사용

- **메뉴바 아이콘 클릭** — 최근 날짜 카드·상태, "오늘 보고서 만들기", 지난 날짜 보고서 만들기.
- **우클릭** — 지금 실행 / 설정 / 종료.
- **설정** — Notion 연결, 요약 엔진(Claude/Codex) 선택, 매일 자동 실행 시각, 업데이트 확인.

아이콘은 정상일 땐 조용하고(무색), 밀린 날짜가 있으면 색으로 알립니다.

---

## 요구사항

- **macOS 14** 이상
- 요약 엔진 CLI — [Claude Code](https://claude.com/claude-code)(`claude`) 또는 Codex(`codex`) 중 하나가 설치·로그인되어 있어야 합니다.
- **Notion 계정** + 통합 토큰(첫 설정에서 안내).

---

## 개인정보 / 보안

- Notion 토큰은 **Keychain**에만 저장됩니다(디스크 평문 없음).
- 수집·요약·적재 전 과정이 로컬에서 동작하며, 네트워크는 **Notion API 호출**과 **요약 CLI 실행**에만 쓰입니다.
- 수집 대상에서 제외할 폴더는 설정 파일로 지정할 수 있습니다(기본적으로 다운로드·문서·데스크톱 등은 제외).
